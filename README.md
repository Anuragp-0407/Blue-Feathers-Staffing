# BLUE FEATHERS Staffing Solutions — Homepage

A responsive React + Vite homepage prototype using the supplied BLUE FEATHERS logo and a four-panel diagonal image hero.

## Run locally

1. Install Node.js (LTS) if it is not already installed.
2. Open this folder in VS Code.
3. In the terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Notes

- The four hero photographs currently load from Unsplash, so an internet connection is needed to display them.
- The service cards are provisional placeholders, not a confirmation of the company's actual service offering.
- No company phone number, email, address, statistics, client logos, or testimonials have been invented.
- The contact CTA is intentionally non-submitting until the real contact details or enquiry workflow are provided.
- Navigation currently scrolls to homepage sections. It can be connected to separate pages when those pages are developed.
